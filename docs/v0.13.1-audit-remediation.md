# V0.13.1 Audit Remediation

V0.13.1 is a bounded corrective release. It makes incomplete input and unavailable
discussion explicit, tightens deterministic token recognition, aligns final discussion
state, minimizes legacy summaries, and narrows the offline evaluator's claims. It does
not add tools, roles, routes, model calls, translation generation, or long-document
chunking.

## Evaluator 2.1 boundary

The repository's 30-case Golden corpus remains a deterministic regression suite that
exercises the production orchestration path. Evaluator Schema 2.1 reports:

- `critical_presence_contract_accuracy`: exact agreement between the fixture's expected
  critical-or-blocking-cluster presence and the observed cluster presence;
- `clean_case_no_cluster_accuracy`: exact no-cluster agreement over cases explicitly
  categorized as clean.

These metrics do not establish defect-identity recall, span recall, severity calibration,
or general false-positive performance. The Golden cases are maintained with the product
and are not an independently curated blind benchmark.

`blind-evaluation-set.schema.json` is only a machine-checkable handoff format for a later
external evaluation. It requires explicit independent-curation provenance and bounded
case annotations; no blind corpus or quality result is supplied by this release.
